**Goal:** Pagina dove il titolare (ditta individuale in forfettario) vede fatturato anno, stima imposte+INPS, % da accantonare e avvicinamento alla soglia €85.000.

**Architettura:** (1) estimatore puro `ForfettarioTaxEstimator` + value objects, senza DB/Filament; (2) servizio `TenantRevenue` che aggrega `treatments.final_price` lato PHP (psql in dev, sqlite in prod → nessuna espressione SQL dialetta-specifica); (3) pagina Filament (solo Admin) con widget stats, grafico mensile e dettaglio calcolo. Parametri fiscali nel JSON `settings` del tenant: **nessuna migrazione**.

**Stack:** Laravel 13, Filament v5.7, PHP 8.5, Pest 4. UI italiana, importi in centesimi (int).

**Spec:** decisioni concordate 2026-11-21: data ricavo = `treatments.created_at`; INPS entrambi i regimi configurabili (fisso € o %); coefficiente default 78, aliquota default 15.

```php
public function estimate(int $revenueCents, TaxConfiguration $config): TaxEstimate
{
    $taxableIncomeCents = (int) round($revenueCents * $config->coefficientPercent / 100);
    $contributionsCents = $config->inpsMode === InpsMode::Percentage
        ? (int) round($taxableIncomeCents * ($config->inpsPercentage ?? 0.0) / 100)
        : ($config->inpsFixedAnnualCents ?? 0);
    $substituteTaxCents = (int) round(
        max(0, $taxableIncomeCents - $contributionsCents) * $config->substituteTaxRatePercent / 100
    );

    return new TaxEstimate($revenueCents, $taxableIncomeCents, $contributionsCents,
        $substituteTaxCents, $contributionsCents + $substituteTaxCents);
}
```

`TaxEstimate::setAsideRate()`: 0.0 se revenue 0, altrimenti `round(total/revenue, 4)`.
