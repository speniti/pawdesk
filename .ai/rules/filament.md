# Filament

## Section and navigation icon conventions
Icon semantics for Filament sections/resources: Heroicon::OutlinedClipboardDocumentList = "Dettagli"/"Informazioni generali" sections (structured records); OutlinedBookOpen = Note sections (free text); OutlinedFolderOpen = Treatments navigation icon. Keep new note sections with BookOpen and detail sections with ClipboardDocumentList.
